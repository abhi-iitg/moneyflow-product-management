# Customer Journey

| Stage | User goal | Pain point | Opportunity | Product response |
|---|---|---|---|---|
| Discover | Find a simple tool | Existing tools feel complex | Clear positioning | "Know what to do next" |
| Onboard | Start quickly | Data/privacy friction | Progressive onboarding | Explain data handling before import |
| Import | Connect data | Formatting uncertainty | Safe validation | Preview + error handling |
| Understand | See current state | Too many transactions | Summarization | Cash-flow snapshot |
| Plan | Decide spending | Fixed budgets feel unrealistic | Flexible planning | Safe-to-spend guidance |
| Act | Change behavior | Advice feels generic | Contextual actions | Explainable prompts |
| Return | Check progress | Forgetting is common | Habit loop | Weekly check-in |
| Advocate | Share value | Referral friction | Goal-based referral | Optional referral after value moment |

## Critical moments

1. **Trust moment:** before data import
2. **Aha moment:** first useful explanation
3. **Action moment:** first completed financial action
4. **Habit moment:** second weekly check-in
