# KPI Dictionary

| KPI | Definition | Type |
|---|---|---|
| Activation | User completes first actionable check-in within 7 days | Primary |
| WAFC | Weekly check-in with meaningful action | North Star |
| W4 retention | Activated users returning in week 4 | Retention |
| Import success | Valid imports / import attempts | Quality |
| Correction rate | Corrected categories / categorized transactions | Quality |
| Budget adoption | Active users with budget / activated users | Engagement |
| Goal adoption | Active users with savings goal / activated users | Engagement |
| Action completion | Completed actions / insight exposures | Value |
| Privacy incident rate | High-severity incidents / active users | Guardrail |
| Deletion success | Successful deletion requests / deletion requests | Trust |
