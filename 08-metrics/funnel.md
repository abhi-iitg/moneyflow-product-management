# Product Funnel

```text
Landing
  ↓
Onboarding started
  ↓
Trust information viewed
  ↓
Import/demo completed
  ↓
First snapshot viewed
  ↓
First action completed
  ↓
Second check-in
  ↓
Week-4 retained
```

## Primary conversion

**Activation = first actionable check-in within 7 days**

## Diagnostic cuts

Analyze by:
- acquisition channel
- persona
- import size
- data quality
- first insight type
- action type

## Important PM rule

Never optimize the funnel only for volume. Pair each conversion metric with a quality or trust guardrail.
