# Stakeholder Plan

| Stakeholder | Need | Cadence | PM responsibility |
|---|---|---|---|
| Engineering | clear scope/dependencies | weekly | unblock decisions |
| Design | validated flows | weekly | protect user problem |
| Data/Analytics | event definitions | weekly | metric ownership |
| Security | data controls | milestone | risk closure |
| Legal/Compliance | product boundaries | milestone | avoid unsafe claims |
| Marketing | positioning/GTM | weekly near launch | align promise |
| Support | FAQ/escalations | pre-launch | prepare feedback loop |
| Leadership | outcomes/risks | biweekly | communicate trade-offs |

## Escalation rule

Escalate decisions that affect:
- user trust
- regulated activity
- data security
- launch-critical scope
- primary metric integrity
