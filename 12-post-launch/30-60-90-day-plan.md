# 30-60-90 Day Plan

## Days 0–30 — Learn

- monitor activation
- inspect failed imports
- interview new users
- identify insight corrections
- validate first-action behavior
- fix critical trust/usability issues

**Decision:** Is the core value loop real?

## Days 31–60 — Improve

- improve onboarding
- improve categorization
- test insight hierarchy
- test weekly check-in
- validate retention drivers

**Decision:** Which behavior drives repeat value?

## Days 61–90 — Scale carefully

- evaluate integrations
- test premium planning
- expand acquisition channels
- measure support and unit economics

**Decision:** Is the product ready to scale?
