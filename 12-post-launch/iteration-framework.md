# Iteration Framework

Every iteration follows:

**Signal → Diagnose → Hypothesis → Experiment → Decision → Document**

## Example

Signal:
> Activation is below target.

Diagnose:
> Largest drop occurs after first snapshot.

Hypothesis:
> Users see information but do not understand the next action.

Experiment:
> Add "What changed?" + one primary CTA.

Decision:
- ship
- iterate
- reject

## Decision log requirement

For every major product decision document:

1. context
2. evidence
3. alternatives
4. decision
5. trade-off
6. expected outcome
7. follow-up metric
