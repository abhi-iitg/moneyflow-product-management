# Wireframe Specification

## Screen 1 — Home

### Header
- "Your financial check-in"
- month selector

### Hero
- income
- expenses
- net cash flow
- safe-to-spend estimate with explanation

### Priority card
**What changed?**

Example:
> Dining spend is above your recent average.

CTA:
**Review transactions**

### Goal card
- goal progress
- remaining amount
- target date

### Design rule

Do not place more than three primary decisions on the first screen.

## Screen 2 — Transactions

- search
- date filter
- category filter
- needs-review filter
- transaction list
- correction action

## Screen 3 — Plan

- category budgets
- savings goal
- recurring commitments
- remaining discretionary room

## Screen 4 — Privacy

- what is stored
- why it is stored
- export
- delete
- data retention explanation
