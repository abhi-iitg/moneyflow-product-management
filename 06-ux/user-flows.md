# User Flows

## Flow 1 — First Value

```text
Landing
 ↓
Privacy explanation
 ↓
Demo or import choice
 ↓
Import preview
 ↓
Validation
 ↓
Categorization
 ↓
First financial snapshot
 ↓
One actionable insight
 ↓
Action completed
```

## Flow 2 — Weekly Check-in

```text
Open app
 ↓
Current month status
 ↓
"Since last check-in"
 ↓
Priority insight #1
 ↓
Action
 ↓
Priority insight #2
 ↓
Optional action
 ↓
Goal progress
 ↓
Complete check-in
```

## Flow 3 — Category Correction

```text
Transaction
 ↓
Incorrect category?
 ↓
Edit
 ↓
Choose category
 ↓
Apply to future similar transactions? [optional]
 ↓
Recalculate summary
```

## Flow 4 — Data Deletion

```text
Settings
 ↓
Data & Privacy
 ↓
Delete financial data
 ↓
Explain consequences
 ↓
Confirm
 ↓
Delete
 ↓
Confirmation
