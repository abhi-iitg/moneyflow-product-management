# User Stories

## Epic: Onboarding

**US-01**  
As a new user, I want to understand how my data is used before importing it, so that I can make an informed trust decision.

**US-02**  
As a new user, I want a sample/demo dataset, so that I can understand the product before using my own data.

## Epic: Transactions

**US-03**  
As a user, I want transactions automatically categorized, so that I do not manually classify every record.

**US-04**  
As a user, I want to correct a category, so that my financial summary becomes more accurate.

## Epic: Planning

**US-05**  
As a user, I want to see current cash flow, so that I understand my monthly position.

**US-06**  
As a user, I want to set a flexible budget, so that I can plan without feeling punished by rigid limits.

**US-07**  
As a user, I want to set a savings goal, so that I can track progress toward something meaningful.

## Epic: Check-in

**US-08**  
As a user, I want a concise weekly check-in, so that I can understand what changed without reviewing every transaction.

**US-09**  
As a user, I want an explanation for each insight, so that I can judge whether it is trustworthy.

## Epic: Privacy

**US-10**  
As a user, I want to delete my data, so that I remain in control of my information.
