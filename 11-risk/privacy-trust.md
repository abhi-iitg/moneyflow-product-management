# Privacy & Trust Strategy

## Trust promise

MoneyFlow should clearly communicate:

- what data is collected
- why it is collected
- how it is used
- how long it is retained
- how it can be deleted
- whether any third party receives it

## MVP boundary

Do not collect bank credentials or OTPs.

Use:
- synthetic demo data
- user-provided exports
- transparent local processing where possible

## Trust UX

Before import:

> "Your transaction file is used to calculate your MoneyFlow insights. You can review the file before saving it and delete your stored data at any time."

## Red lines

Never:
- sell personal financial data
- hide data sharing
- claim financial certainty
- impersonate a regulated advisor
- make autonomous financial decisions

## Incident response

1. stop affected processing
2. preserve audit evidence
3. notify internal owner
4. assess scope
5. communicate appropriately
6. remediate
7. post-incident review
